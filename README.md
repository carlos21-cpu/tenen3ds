# Portal de Pagos - Control Vehicular

Proyecto exportado de Lovable a Vite + React + TypeScript + react-router-dom.
Sin TanStack Start, sin Cloudflare Workers, sin SSR.

## Requisitos
- Node.js 18+

## Instalacion
```bash
npm install
```

## Desarrollo
```bash
npm run dev
```

## Build de produccion
```bash
npm run build
npm run preview
```

## Estructura
- `src/main.tsx` - Entry point con BrowserRouter
- `src/pages/Index.tsx` - Pagina principal (toda la app)
- `src/styles.css` - Tailwind v4 + design tokens
- `src/assets/` - Imagenes
- `src/lib/utils.ts` - Helpers (cn)
